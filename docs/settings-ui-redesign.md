> 日期：2026-10-03 ｜ 目标：把现在"一堆 Card 堆叠 + Tag 罗列"的设置页，改成 Cherry Studio 式的**三栏主从结构**

## 1. 参考对象拆解（实测截图）

### Cherry Studio「设置 → 模型服务」（主要对标）
截图：`reference/cherry-provider-light.png`（2130×1392）

**结构**：三栏主从
| 栏位 | 宽度 | 内容 |
|---|---|---|
| ① 全局设置导航 | ~300px | 分组列表：模型服务 / 默认模型 / 本地模型 / API 网关 ｜ 工具：MCP / 技能 / 网络搜索 / 文档处理 / OCR ｜ 偏好：外观 / 通知 / 数据 / 用量统计 / 频道 / 定时任务。分组标题 12px 灰，条目 15px，选中项浅灰圆角高亮 + 左侧图标 |
| ② 供应商列表 | ~370px | 顶部**搜索框**（"搜索模型平台…" + 右侧筛选漏斗）→ 供应商行（20px logo + 名称 + 右侧 6px 状态点；部分带绿色「免费」小标签）→ 底部通栏「+ 添加服务商」。选中行：浅灰圆角块（#00000008 级别），未选中纯白 |
| ③ 供应商详情 | 自适应 | 标题（名称 + ⓘ 说明）+ 右上**绿色大开关**（启用/禁用）；「API 密钥」标签 + 右侧文字链「获取密钥」→ 密码框（框内眼睛图标）+ 框外两个图标动作（钥匙、心跳=连通检查）；「API 地址」标签 + 「添加端点」链接 → 下拉框（预置端点）+ 齿轮；「模型」区：小标题行 + 一排图标工具（导入/清空/搜索/筛选）+ 右侧「⟳ 获取模型列表」按钮 +「+」；模型按能力分组折叠（agent / baai …），每行 = 模型 logo + 名称 + 右侧能力徽章（💡推理 / 🔧工具 / 👁视觉 / 🎥视频）+「−」移除 |

**视觉规律（可直接抄的语言）**
- 底色纯白/极浅灰，靠**留白与分隔线**分区，几乎不用边框与阴影
- 圆角统一 10–12px；行高 48–56px；图标 16–20px 灰色线性
- 文字层级：区块标题 15–16px/600；字段标签 14px/500 灰；正文 14px
- 颜色只用在"状态"上：绿点/绿开关 = 可用；浅色 pill 表示能力标签
- 输入框是**填充式**（浅灰底、无边框、focus 变白 + 主色描边），不是描边式
- 每个动作都有就地反馈（右上开关、行尾「−」、行内图标按钮）

### Toonflow（首次配置 + 画布）
- `toonflow-quickStart.png`：深色单页 onboarding —— 大标题「快速开始」+ 一句灰色说明 + **一个主按钮**（"登录 TF-Router 自动配置"）+ 两个 ghost 次按钮（"添加私有提供商"/"稍后配置"）；右侧大幅艺术图。**信息极简，主次分明**

## 2. 现状问题（对照妙绘 SettingsView）

1. **信息密度失衡**：所有供应商用同一个 `provider-row` 平铺，每个供应商下面直接摊开"添加模型"行内表单（ID/显示名/能力复选框/添加按钮），页面又长又乱
2. **主次不分**：密钥、模型、默认值、服务状态、数据目录、关于全是等权重 Card，用户找不到重点
3. **控件风格陈旧**：描边输入框 + `Space.Compact` 按钮组横排，缺少分组与呼吸感；能力标签是纯文字 Tag，没有视觉语言
4. **缺少状态反馈**：供应商是否可用只靠一个小圆点；模型是否启用没有开关；列表没有搜索
5. **空态缺失**：没有供应商时没有引导

## 3. 新设计方案（妙绘落地版）

### 3.1 信息架构

```
设置
├─ 模型服务        ← 本次重做（两栏主从）
├─ 默认模型        ← 从模型服务里拆出来，独立入口（生图 / 文本 / 视觉）
├─ 服务状态        ← 接入点、连通性、最近错误、日志入口
├─ 数据与目录      ← 作品目录 / 案例库 / 打开目录
└─ 关于
```

设置页内部：**左侧 240px 二级导航（上述 5 项）+ 右侧内容区**。
> 妙绘已有一级左侧导航（创作/合成/灵感库/反推/历史/设置），设置页内再放一层 240px 是会偏深的，但 Cherry Studio 正是这么做的且很清爽——因为一级导航是"工作区"，二级是"设置分区"。可接受；若嫌深，退化为**顶部 Tab**（模型服务 / 默认模型 / 服务状态 / 数据 / 关于）。

### 3.2 模型服务页（两栏主从）

```
┌─ 供应商列表 280px ────────┬─ 供应商详情 flex ─────────────────────────┐
│ [🔍 搜索供应商…]          │  阿里云百炼            ⓘ        [●—— 启用] │
│ ─────────────────────     │                                            │
│ ▢ 阿里云百炼        ●     │  API 密钥          获取密钥                │
│ ▢ 硅基流动          ○     │  [•••••••••••••••••  👁 ] [🔑] [♡ 测试]   │
│ ▢ OpenAI            ○     │                                            │
│ ▢ 我的网关(自定义)  ●     │  API 地址          添加端点                │
│                           │  [ https://…maas.aliyuncs.com  ▾ ] [⚙]     │
│ ─────────────────────     │                                            │
│ [+ 添加服务商]            │  模型        [🔍] [筛选]      [⟳ 拉取模型列表] [+]│
│                           │  ┌──────────────────────────────────────┐ │
│                           │  │ wan2.7-image    [生图]      [删除]   │ │
│                           │  │ qwen3.8-flash   [文本]      [删除]   │ │
│                           │  │ qwen3-vl-plus   [视觉][文本] [删除]   │ │
│                           │  └──────────────────────────────────────┘ │
└───────────────────────────┴────────────────────────────────────────────┘
```

**关键交互**
- 列表项右侧状态点：绿=已配密钥；灰=未配置；红=最近调用失败
- 点击供应商 → 右侧切换详情（不跳页）；列表底部「+ 添加服务商」→ 现有 Modal 保留
- 「拉取模型列表」后，新模型以**带虚线的 pill** 追加在列表下方（已有实现），点击 pill 可直接设为默认
- 模型行尾「删除」只对用户添加/拉取的模型可用；内置模型显示为锁定态（灰色小锁）
- 「测试」按钮 = 现有 `test:provider`（拉 /models，免费），结果就地显示为行内提示条

**视觉规范（design tokens）**
| 项 | 值 |
|---|---|
| 布局栅格 | 8px 基准；页面 padding 24；卡片 padding 20 |
| 圆角 | 列表项 10px / 输入框 8px / 卡片 12px / pill 999px |
| 分隔线 | `1px solid rgba(0,0,0,0.04)` |
| 选中态 | `background: rgba(0,0,0,0.03)`；hover `rgba(0,0,0,0.02)` |
| 输入框 | 填充式：底 `#f5f5f7`、无边框、`8px`；focus 白底 + `1px #1677ff` |
| 主色 | antd 蓝 `#1677ff`（仅用于主按钮/链接/focus） |
| 状态色 | 成功 `#52c41a`、警告 `#faad14`、失败 `#ff4d4f` |
| 能力 pill | 生图 `#f9f0ff/#722ed1`、文本 `#e6f4ff/#1677ff`、视觉 `#f6ffed/#52c41a` |
| 字号 | 页标题 20/600 · 区块 15/600 · 标签 13/400 灰`#8c8c8c` · 正文 14 |
| 图标 | 16px 线性（antd 默认），仅状态与主操作着色 |

### 3.3 默认模型页
三张并排的"能力卡"（生图 / 文本 / 视觉），每卡：能力 pill + 当前模型名 + 供应商 logo + 下拉切换 + 「用量/单价」灰字说明。比现在的三个 Select 竖排更好扫。

### 3.4 服务状态页
- 顶部一条状态条：绿/红圆点 + `服务在线 · llm-xxxx.cn-beijing.maas.aliyuncs.com` + 右侧「重新检测」
- 三行指标：接入点、密钥（掩码）、最近一次调用耗时
- 失败时展示：错误原文（可复制）+ 「打开日志目录」

## 4. 实施拆解（可分批交付）

| 批次 | 内容 | 影响文件 | 风险 |
|---|---|---|---|
| S1 | 设置页拆成 5 个分区 + 顶部/侧边导航；供应商列表（搜索+状态点+选中态） | `SettingsView.tsx`（拆分为 `settings/` 目录）、新增 CSS | 低（纯前端） |
